Privacy Policy

Last Updated: October 3, 2026

This Privacy Policy explains how nexar.click and NEXT BYTE ("we", "us", or "our") collect, use, process, store, and delete information when you interact with our temporary email infrastructure, browser extensions, Telegram bots, Discord bots, websites, and file-processing utilities (collectively, the "Service").

1. About the Service Scope

Our infrastructure covers two primary service components:

  • nexar.click Mail Infrastructure: Free temporary email hosting, mailbox generation, Telegram notification bots, and browser extension tools strictly designed for educational evaluation, software testing, and spam prevention.
  • NEXT BYTE Discord Utility & Media Processing: A third-party Discord application offering file conversion, video/audio processing, PDF manipulation, file compression, and supported media downloads.

NEXT BYTE is independently operated and is not affiliated with, endorsed by, or sponsored by Discord Inc.

2. Information We Collect

A. Mail Server & Email Infrastructure (nexar.click)

When you interact with our mail infrastructure, browser extensions, or Telegram email bots, we collect strictly minimal network and message data required to route emails:

  • Email Transmission Data: Sender address, recipient temp address, email headers, subject lines, message bodies, and attachments.
  • Connection Metadata: IP addresses, access timestamps, user-agent details, and mail server routing records for security and abuse monitoring.
  • Telegram Interactions: Telegram user ID and chat ID when linking temporary email notifications to your Telegram account.

B. Discord Bot & File Processing (NEXT BYTE)

When you interact with NEXT BYTE via Discord, we receive data through Discord's API, including:

  • Discord Platform Data: Discord user ID, display name, server/channel IDs, command interactions, and timestamps.
  • Uploaded Files & URLs: Uploaded images, audio, video, PDFs, document archives, and platform URLs provided for downloading or conversion.

We never request or store your Discord passwords, authentication tokens, or personal payment card details.

3. How Files & Emails Are Processed

All content submitted to nexar.click or NEXT BYTE is processed on an automated, temporary basis:

  • Isolated File Jobs: Files uploaded to NEXT BYTE are assigned unique, randomized job identifiers and isolated temporary directories to prevent unauthorized user access.
  • Temporary Mail Storage: Incoming emails sent to generated temporary addresses are stored in memory or volatile database storage until auto-purged upon inbox expiration.
  • No Profiling or AI Training: We do not sell, rent, or profile your data. Uploaded files and received emails are never used for commercial advertising or training AI models.

4. Temporary Data Retention & Auto-Deletion

Automatic Cleanup Rules:
  • Temporary Email Inboxes: Inboxes and message contents are automatically purged within 24 to 48 hours of creation/expiration.
  • File Processing Jobs: Uploaded and converted files on NEXT BYTE are automatically deleted within 1 to 2 hours after job completion.
  • Logging Data: Technical logs (IP addresses, rate-limiting counters, and security records) are retained for up to 30 days for abuse prevention before deletion.

Note: Occasional delays in deletion may occur due to technical failures, system backups, or infrastructure maintenance. Do not use this Service as a primary storage solution.

5. URLs & Media Downloading Features

If you use NEXT BYTE's media downloader features, you provide URLs from third-party platforms (e.g., YouTube, Instagram, Facebook). We process these URLs exclusively to retrieve publicly accessible media. NEXT BYTE does not intentionally bypass DRM, authentication controls, paywalls, or private-account restrictions.

6. How We Use Collected Information

We use operational data solely to:

  • Deliver temporary email messages and file conversions.
  • Manage queue capacity, rate limits, and server performance.
  • Prevent system spam, infrastructure attacks, and policy violations.
  • Diagnose technical bugs and maintain server health.
  • Comply with valid legal requests and legal obligations.

7. Data Sharing & Infrastructure Providers

We do not sell or lease personal information. Data may be processed through core cloud infrastructure necessary to operate the Service, including VPS hosts, cloud processing nodes, security filtering services, and database providers. We may also disclose metadata if required by valid law enforcement requests or legal process.

8. Security Measures

We implement technical controls to safeguard temporary data, including HTTPS/TLS encryption in transit, temporary isolated sub-directories, strict upload size limits, execution timeouts, automatic cleanup cron jobs, and restricted server access.
